# chat-thread-vs-library

## Chat thread

Conversacion persistente asociada a un usuario dentro de un proyecto. Guarda mensajes y relaciones con assets usados en ese contexto conversacional.

## User library

Biblioteca persistente del usuario dentro del mismo proyecto. Permite conservar assets mas alla de un mensaje puntual y reutilizarlos despues.

La decision actual del portafolio es soportar `chat + biblioteca`, no solo uno de los dos.
