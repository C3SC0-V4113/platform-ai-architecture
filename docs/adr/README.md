# ADR Index

Este directorio contiene las Architecture Decision Records del portafolio.

## Convencion

- Formato de nombre: `NNNN-short-title.md`
- Numeracion secuencial de 4 digitos.
- Estados sugeridos: `Proposed`, `Accepted`, `Superseded`, `Deprecated`.

## Regla de uso

- Las decisiones cerradas van aqui.
- La exploracion abierta y las preguntas pendientes viven en `docs/discovery/`.
- Si una decision cambia, no se reescribe la historia: se crea un nuevo ADR que la supersede.
