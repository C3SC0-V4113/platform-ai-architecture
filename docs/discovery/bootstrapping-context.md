# Bootstrapping Context

Este repo nace para consolidar definiciones del portafolio AI que antes estaban dispersas.

## Decisiones ya tomadas

- estrategia multi-repo;
- `other-gpt` como satelite de chat;
- `auth-service` como producto base central;
- persistencia por proyecto;
- un chat continuo por usuario por proyecto;
- assets persistentes asociados al chat y a una biblioteca del usuario;
- `knowledge-rag` no es el source of truth de archivos;
- `mcp-server` expone tools, no reemplaza APIs internas;
- `openclaw-ops` se usa como interfaz operativa.

## Objetivo del repo

Mantener el learning path como base del plan y fijar fronteras claras entre proyectos.
